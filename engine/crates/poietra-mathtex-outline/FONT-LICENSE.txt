New Computer Modern Math font provenance
========================================

This crate embeds the unmodified `NewCMMath-Regular.otf` from New Computer
Modern version 8.1.1 by Antonis Tsolomitis. The font was obtained from the
official CTAN package:

https://ctan.org/pkg/newcomputermodern

The upstream package states that this font is distributed under the GUST Font
License. The font file embedded here is unmodified.
